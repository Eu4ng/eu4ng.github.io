control plane에서 스크립트를 실행해 Helm과 Headlamp를 설치하고, 내 PC의 브라우저에서 토큰으로 로그인합니다. Kubernetes Dashboard는 2026년 1월에 저장소가 보관 처리되어 더 이상 관리되지 않으므로, 공식적으로 안내하는 후속 도구인 Headlamp를 사용합니다.

1. 스크립트 내려받기
2. 스크립트 실행
3. 브라우저에서 로그인

## 사전 준비

> 이미 준비되어 있는 경우 건너뛰셔도 됩니다.
{: .prompt-info }

아래 환경을 기준으로 작성했습니다.

| 항목 | 버전 |
| :--- | :--- |
| Kubernetes | `v1.37` |
| Helm | `4.3` |
| Headlamp | `0.45 (Helm 차트)` |
| 작성 기준일 | `2026-09-20` |

다음 항목이 준비되어 있어야 합니다.

- `kubectl`로 접근할 수 있는 쿠버네티스 클러스터 (만드는 방법은 [Proxmox에 kubeadm으로 쿠버네티스 클러스터 설치하는 방법](/posts/32/) 참고)
- 내 PC에서 클러스터 노드의 IP로 접속할 수 있는 네트워크

## 1. 스크립트 내려받기

control plane에 SSH로 접속해 스크립트를 내려받습니다.

```bash
# control plane 접속 후 설치 스크립트 내려받기
ssh ubuntu@[CP_IP]
wget https://eu4ng.github.io/assets/scripts/kubernetes/install-headlamp.sh
```

<details markdown="1">
<summary>스크립트 전문 보기</summary>

```bash
#!/usr/bin/env bash
#
# 쿠버네티스 클러스터에 Headlamp 대시보드를 Helm 으로 설치하고 로그인 토큰을 출력합니다.
# kubectl 로 클러스터에 접근할 수 있는 곳(예: control plane)에서 실행합니다: bash install-headlamp.sh

set -euo pipefail

# ---------- 환경에 맞게 수정 ----------
NODEPORT=30080             # 브라우저로 접속할 포트 (30000-32767)
NAMESPACE=headlamp
# --------------------------------------

HELM_INSTALL_URL=https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4
CHART_REPO=https://kubernetes-sigs.github.io/headlamp/
TOKEN_SECRET=headlamp-admin-token

log() { echo -e "\n\033[1;32m==>\033[0m $*"; }
die() { echo -e "\033[1;31m[오류]\033[0m $*" >&2; exit 1; }
trap 'echo -e "\033[1;31m[오류]\033[0m ${LINENO}번째 줄에서 중단되었습니다." >&2' ERR

# ---------- 1. 사전 검사 ----------
log "사전 검사"
kubectl get nodes >/dev/null || die "kubectl 로 클러스터에 접근할 수 없습니다."

# ---------- 2. Helm ----------
if ! command -v helm >/dev/null; then
  log "Helm 설치"
  curl -fsSL "$HELM_INSTALL_URL" | sudo bash
fi

# ---------- 3. Headlamp ----------
# 차트가 ServiceAccount(headlamp)와 cluster-admin 권한을 함께 만듭니다.
log "Headlamp 설치"
helm repo add headlamp "$CHART_REPO" --force-update
helm repo update headlamp
helm upgrade --install headlamp headlamp/headlamp \
  --namespace "$NAMESPACE" --create-namespace \
  --set service.type=NodePort --set service.nodePort="$NODEPORT" \
  --wait --timeout 5m

# ---------- 4. 로그인 토큰 ----------
# 만료되지 않는 ServiceAccount 토큰을 Secret 으로 만듭니다.
log "로그인 토큰 생성"
kubectl apply -f - <<TOKEN
apiVersion: v1
kind: Secret
metadata:
  name: $TOKEN_SECRET
  namespace: $NAMESPACE
  annotations:
    kubernetes.io/service-account.name: headlamp
type: kubernetes.io/service-account-token
TOKEN

token=
for _ in $(seq 1 30); do
  token=$(kubectl get secret "$TOKEN_SECRET" -n "$NAMESPACE" -o jsonpath='{.data.token}' | base64 -d)
  [ -z "$token" ] || break
  sleep 1
done
[ -n "$token" ] || die "토큰이 생성되지 않았습니다."

node_ip=$(kubectl get nodes -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
log "완료. 브라우저에서 접속한 뒤 아래 토큰으로 로그인합니다."
echo "  http://$node_ip:$NODEPORT"
echo
echo "$token"
```
{: file="install-headlamp.sh" }

</details>

- **확인:** 현재 폴더에 `install-headlamp.sh` 파일 생성

## 2. 스크립트 실행

스크립트를 실행하면 아래 작업이 순서대로 진행됩니다. 접속 포트를 바꾸려면 스크립트 맨 위의 `NODEPORT`(기본값 `30080`)를 먼저 고칩니다.

```bash
# Helm 과 Headlamp 설치
bash install-headlamp.sh
```

1. Helm이 없으면 설치
2. Headlamp 차트를 `headlamp` 네임스페이스에 NodePort 서비스로 설치
3. 만료되지 않는 로그인 토큰을 만들어 접속 주소와 함께 출력

- **확인:** 마지막에 `http://[CP_IP]:30080` 형태의 주소와 토큰 출력

## 3. 브라우저에서 로그인

내 PC의 브라우저에서 출력된 주소로 접속하고, 토큰 입력 화면에 출력된 토큰을 붙여 넣습니다. 토큰을 다시 확인하려면 control plane에서 아래 명령을 실행합니다.

```bash
# 로그인 토큰 다시 출력
kubectl get secret headlamp-admin-token -n headlamp -o jsonpath='{.data.token}' | base64 -d
```

> 이 토큰은 클러스터 전체 관리자 권한을 가지며 만료되지 않고, 접속은 암호화되지 않은 HTTP입니다. 신뢰할 수 있는 내부 네트워크에서만 사용하고 포트를 외부에 열지 않습니다.
{: .prompt-danger }

- **확인:** 로그인 후 **Cluster** > **Nodes**에 클러스터의 노드가 표시

## 마무리

스크립트 하나로 Helm과 Headlamp를 설치하고 브라우저에서 클러스터를 확인했습니다. 내부 네트워크 전용 구성이므로, 외부에서 접속해야 한다면 TLS를 적용한 Ingress와 OIDC 로그인을 따로 구성해야 합니다.
