무엇을 하는 글인지보다 어떤 순서로 진행하는지를 한두 문장으로 안내합니다. 단계가 네 개 이상이면 번호 목록으로 요약합니다.
공식 문서의 방식과 다르게 진행했다면 무엇이 다른지 여기서 한 문장으로 밝힙니다.

1. 단계 제목
2. 단계 제목

## 사전 준비

> 이미 준비되어 있는 경우 건너뛰셔도 됩니다.
{: .prompt-info }

아래 환경을 기준으로 작성했습니다.

| 항목 | 버전 |
| :--- | :--- |
| 운영체제 | `예: Windows 11 24H2` |
| 핵심 도구 | `예: Docker Desktop 4.40` |
| 작성 기준일 | `YYYY-MM-DD` |

다음 항목이 준비되어 있어야 합니다.

- 미리 설치되어 있어야 하는 도구 (설치 명령이 있으면 바로 아래에 bash 블록으로 적습니다)
- 필요한 계정과 권한
- 먼저 읽어야 하는 글이 있다면 [글 제목](/posts/N/) 링크

## 1. 단계 제목

이 단계에서 무엇을, 왜 하는지 한 문장으로 적습니다.

1. **메뉴** > **하위 메뉴**로 이동
2. **버튼 이름** 클릭
3. 아래 값을 입력
   - **항목 이름**: `값`

```yaml
services:
  app:
    image: [IMAGE_NAME]
```
{: file="docker-compose.yml" }

- **확인:** 이 단계가 성공했을 때 화면이나 출력에 무엇이 보이는지 적습니다.

## 2. 단계 제목

```bash
# 무엇을 하는 명령인지
command --option [VALUE]
```

> 실수하기 쉬운 부분이나 버전에 따라 달라지는 동작을 적습니다.
{: .prompt-warning }

- **확인:** 기대하는 출력이나 상태를 적습니다.
